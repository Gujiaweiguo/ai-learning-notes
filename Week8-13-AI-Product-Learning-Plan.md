# Week 8-13 AI Product Learning Plan

## Goal

This six-week sequence extends the completed Week 1-7 AI foundation. It does not restart learning. It turns that foundation into product architecture understanding for LangChat and Vision Intelligence planning for MallSenseAI.

```
Week 1-7:   AI foundations (completed)
Week 8-11:  LangChat Mental Model
Week 12-13: Vision Intelligence Capability Map
Week 14+:   Business-management systems and delivery sprints
```

## Product Architecture Order

```
LangChat (enterprise AI application platform)
  -> MallSenseAI (Vision Intelligence industry capability pack)
  -> Business-management systems (business application layer)
```

## Week 8: End-to-End Journey

Follow one complete request path rather than studying isolated modules.

- Day 1: User intent and Agent Host. Why is LangChat not an Agent Host?
- Day 2: ApplicationContract. Why is a contract not API documentation?
- Day 3: Blueprint -> Compiler -> ExecutionPlan. Why cannot a Blueprint run directly?
- Day 4: Runtime. Why must Runtime remain stateless?
- Day 5: Capability + Connector -> Enterprise System. Why is a Capability not a plugin?
- Day 6: Draw the full request journey with inputs and outputs.
- Day 7: Virtual CTO review: identify the weakest link.

## Week 12: Vision Intelligence Landscape and MallSenseAI Baseline

MallSenseAI is not a CV demo or a YOLO platform. It is a future Vision Intelligence industry capability pack for LangChat.

Vision Capability Layers:

```
L1 Image Understanding: Detection, OCR, Segmentation
L2 Video Understanding: Tracking, MOT, Video Analytics
L3 Scene Understanding: Counting, Heatmap, Crowd, Queue
L4 Business Intelligence: customer-flow KPI, safety events, operational metrics
L5 Vision Agent: analysis, reasoning, suggestions, daily reports
```

- Day 1: Vision Intelligence landscape
- Day 2: MallSenseAI repository and pipeline
- Day 3: Detection system choices
- Day 4: Video Analytics baseline
- Day 5: Business Scene Matrix
- Day 6: Vision five-layer map and Business Scene Matrix
- Day 7: Virtual CTO review

## Daily Outputs

Every learning day records:

1. What is better understood today?
2. One core question in the form “Why is X not Y?”
3. If LangChat were redesigned today, would this decision remain valid? Why?
4. Daily Engineering Log: added, changed, deleted, confirmed, unresolved, debt, next step.
5. Engineering Journal: biggest insight, pitfall, and decision.
